# 快捷操作使用说明

## 参数表单

工具默认先展示快捷参数；展开“高级参数”可查看完整参数。有明确默认值的字段自动预填，固定枚举使用下拉框。主体名称、域名、输入文件等属于用户真实信息，不代填虚构值。IV、nonce、salt不使用固定零值作为默认值。切换工作模式后以该模式的约束为准。

## 生成并使用密钥

1. 在算法参数旁或项目密钥库选择“生成密钥 (SSL)”。
2. 选择该算法实际支持的GmSSL或OpenSSL来源，再选择长度或曲线。不可用来源不代替成其他来源。
3. 默认“加密托管”，成功后自动选择项目内的密钥引用；原始私钥不直接填进普通文本框。
4. 私钥文件的保护口令留空时，平台生成随机口令并加密托管。后续工具选中该私钥时自动使用关联口令，仍可显式填写口令覆盖。
5. “仅本次使用”不会把材料登记为持久密钥：对称密钥只保留在当前表单，临时文件受任务绑定、结束清理和过期机制管理。需要以后解密时，应使用并保留同一份托管密钥。

OpenSSL生成的SM2/EC密钥经过格式转换后用于GmSSL业务工具。SM9主密钥/用户密钥及有状态签名等使用对应的专用生成工具，不用随机字节代替其密钥结构。可用算法以服务器能力列表为准，OpenSSL的新ML-KEM与固定GmSSL的Kyber格式不混用。

“查看口令”是显式操作，仅有编辑权限的用户可执行并记录审计。补录/更新托管口令记录并不重新加密原私钥文件；应填该文件实际使用的口令。导出带密私钥时也要妥善保留其口令。

## 证书快捷向导

在“证书工具”打开“证书快捷向导”，选择场景：

| 场景 | 需要准备 | 默认有效期 |
|---|---|---|
| 自签名证书 | 名称、用途、主体CN和需要的SAN | 365天 |
| 根CA | CA名称和主体 | 3650天 |
| 中间CA | 上级CA证书与匹配私钥、主体 | 1825天 |
| CSR申请 | 主体、所需SAN，生成或选择自己的私钥 | 不决定最终证书有效期 |
| CA签发 | 已有CSR、CA证书与匹配私钥、用途 | 365天 |
| TLCP双证书 | 主体、SAN；可指定已有CA | 365天 |

向导依次填写主体/SAN、密钥/发行者和有效期。生成新私钥时默认托管且免重复输入口令；选择历史私钥且口令尚未托管时，需要输入其原口令。CA签发复用CSR已经签名的主体，不必重新填写CN。SAN可填写域名或IP地址，签发后应检查实际证书扩展。

TLCP使用独立签名、加密两把SM2私钥和两张用途不同的证书；部署时证书链和私钥PEM的顺序需要匹配。向导提供的材料应以结果列表为准，勿将单张证书当作双证组合。

生成过程显示实际步骤及任务结果，失败时查看失败阶段。已成功托管的材料会在结果中列出；它们与整个工作流“签发完成”不是同一状态。下载证书后仍需由使用端配置信任、证书链与私钥，生成证书不会自动替换当前HTTP服务。

## 使用注意

- SM4是对称加密算法，生成的是SM4密钥；国密身份证书通常使用SM2。
- 固定上游SM4-ECB工具不做填充，输入应为16字节倍数；普通文本使用支持PKCS#7填充的CBC等模式，并按工具要求配置IV。
- 自签名证书需要客户端显式信任；SM2证书的浏览器适配与普通RSA/ECDSA HTTPS证书不同。
- 本轮保持现有IPv6及mac.sjser.ccwu.cc入口，未自动启用HTTPS或公网隧道。
