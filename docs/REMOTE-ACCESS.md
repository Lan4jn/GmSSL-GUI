# 远程与局域网访问方案与操作指南 (Access & Network Guide)

本指南记录 GmSSL-GUI 的网络暴露策略、访问方式演进、当前 IPv6 本地直连监听配置及安全边界说明。

---

## 1. 访问模式演进与状态

1. **公网隧道模式（已撤销停止）**：
   - 此前曾通过 Cloudflare Quick Tunnel 提供临时公网中继测试（`trycloudflare.com`）；
   - **当前状态**：依用户要求，已执行 `./scripts/remote-access.sh stop` 彻底关闭隧道与反向代理，无任何 `cloudflared` 进程残留，`.runtime/remote-access.json` 已置为 `STOPPED`。
2. **本机 IPv6 Web 监听模式（当前生效）**：
   - 响应用户本地 IPv6 访问需求，前端 Web 服务（Vite）监听主机已由单回环 `127.0.0.1` 切换为通用 IPv6/IPv4 接口绑定（`::`）；
   - 后端核心服务（平台服务 8080、执行引擎 8081）严格维持仅 `127.0.0.1` 本地回环监听，由前端 Vite 内部反向代理进行安全转发。

## 2. 当前 IPv6 直连访问地址与配置

### 2.1 可访问地址一览
- **本机全局单播 IPv6 (en6 物理网卡)**：  
  `http://[2408:8459:a60:50db:c87:2f4a:4c8f:b7cd]:5173/`
- **IPv6 本地回环**：  
  `http://[::1]:5173/`
- **IPv4 本地回环**：  
  `http://127.0.0.1:5173/`

### 2.2 启动与环境变量配置
在 `scripts/dev.sh` 中配置了 `GMSSL_WEB_HOST` 环境变量（默认值为 `::`）：
```bash
# 启动 Web 服务（默认监听 ::，同时支持 IPv6 与 IPv4）
bash scripts/dev.sh web-start

# 查看 Web 运行状态与受管 PID
bash scripts/dev.sh web-status

# 停止 Web 服务
bash scripts/dev.sh web-stop

# 恢复仅限 IPv4 本地回环（回退安全模式）
GMSSL_WEB_HOST=127.0.0.1 bash scripts/dev.sh web-start
```

## 3. 安全边界与外部网络可达性说明

1. **后端仅回环隔离**：
   - `platform-service` 绑定端口 `8080`，只监听 `127.0.0.1`；
   - `engine-service` 绑定端口 `8081`，只监听 `127.0.0.1`；
   - 局域网或外部流量仅能触达 Web 前端（5173 端口），所有 API 请求经由 Vite 代理安全转交后端，外部网络无法直连后台数据库或密码执行引擎。
2. **零系统网络配置篡改**：
   - 本配置未关闭 macOS 系统防火墙，未在宿主机路由器上开启端口映射（UPnP/NAT-PMP），未开启 SSH 密码远程登录或 RDP 服务。
3. **外网路由可达性客观界定**：
   - 本套件已在本机真实验证了对 `[::1]:5173`、`[2408:8459:a60:50db:c87:2f4a:4c8f:b7cd]:5173` 及 `127.0.0.1:5173` 的 HTTP 200 与 `/api/v1/*` 链路连通性；
   - **请注意**：因局域网外部设备是否能通过该 IPv6 公网地址直连，取决于运营商光猫/上级路由器的 IPv6 防火墙入站入流量（Inbound Traffic）过滤策略，由于当前尚未从完全独立的外部物理网络机器上发起端到端探测，**本报告明确注明不宣称外部广域网路径一定畅通**。
