# 证书专用简单模式与材料库默认拓扑态核实报告 (task-98)

## 1. 现状定位与文件行号
- **导航定义**：`web/src/App.vue` line 19-20，`navigation` 包含 9 项导航（工作台、算法工具、密钥库、证书工具、协议任务、任务历史、项目与成员、审计日志、用户管理）。
- **材料库子 Tab 状态**：`web/src/App.vue` line 18 `const keysSubTab = ref<'all' | 'tree'>('all')`；项目切换监听在 line 30 `watch(projectId, ...)` 未重置 `keysSubTab`。
- **简单工作台卡片**：`web/src/components/SimpleWorkbench.vue` line 276-380，当前渲染 6 张平铺卡片（制作证书、生成密钥、文件加解密、数字签名、哈希摘要、我的材料库）。

## 2. 证书专用轻量化裁剪方案（纯前端收敛，不删后端能力）
1. **导航菜单收敛（简单模式下）**：
   - 隐藏：`tools`（算法工具目录）、`protocol`（协议任务）；
   - 保留：`dashboard`（工作台/证书主流程）、`keys`（证书材料库）、`jobs`（签发任务历史）、`projects`（项目与协作管理）、`users`（系统管理，ADMIN可见）、`audit`（审计日志，经理可见）。
2. **首页任务卡收敛**：
   - 移除通用算法卡：生成密钥、文件加解密、数字签名、哈希摘要（全部统一收纳至高级模式）；
   - 保留核心证书入口：保留首屏居中“制作证书向导”大卡，以及“证书材料库”卡片，首屏聚焦 100% 证书签发业务。
3. **证书库默认展示 CA 拓扑**：
   - `App.vue` line 18 将 `keysSubTab` 初始值设为 `'tree'`；在 line 30 `watch(projectId)` 增加 `keysSubTab.value = 'tree'`；
   - 保证进入密钥材料库即呈现直观的 CA 树，纯私钥不造伪 CA 关系，通过 `[全部材料与密钥]` 次级 Tab 仍可管理底层私钥。
4. **不可误删的核心安全边界**：
   - 顶栏项目下拉切换（`#project-switch`）、账号信息与退出登录；
   - 项目所有者对成员角色的授权与管理（`page==='projects'`）；
   - 证书向导 4 大 Profile（自签名、根 CA、CSR 申请、已有 CA 快速签发）及无 CA 引导按钮；
   - 私钥敏感隔离、二次确认导出与任务诊断日志保留。
